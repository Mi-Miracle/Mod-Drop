Привіт! Давай налаштуємо 👋

Займе ~5 хвилин. Все, що введеш, зашифрується твоїм паролем і збережеться на цьому ПК, тож наступного разу достатньо буде ввести тільки пароль.

⚙️ Налаштування

Після збереження зміни застосуються одразу.

1

Майстер-пароль

Цим паролем шифруються всі ключі (AES-256-GCM + scrypt). Без нього файл data/config.enc нікому не прочитати.

⚠️ Запам'ятай його. Якщо забудеш, ключі доведеться ввести заново.
2

Твій Twitch-канал

Модерів саме цього каналу пускатиме в панель.

Це те, що в адресі twitch.tv/ось_це.
👥 Список модерів, видачу й відбір доступу, паузи та кулдауни налаштовуєш у панелі: блок «Модератори» внизу.
3

Доступ з інтернету (ngrok)

Щоб модери могли відкрити панель зі своїх ПК. Програма сама запускає ngrok, окремо качати нічого не треба.

Використовувати ngrokРекомендовано. Вимкни, тільки якщо маєш свій сервер чи домен.
Як отримати authtoken і домен
  1. Зареєструйся безкоштовно: dashboard.ngrok.com/signup
  2. Відкрий Your Authtoken, натисни Copy і встав у поле «Authtoken».
  3. Відкрий Domains. На безкоштовному тарифі там уже є (або створюється кнопкою + New Domain) один постійний домен на кшталт щось-щось.ngrok-free.app.
  4. Скопіюй цей домен (без https://) у поле «Статичний домен».
  5. Постійний домен важливий: адреса не міняється, і Twitch-вхід не зламається після перезапуску.
  6. Перший раз модери побачать сторінку-попередження ngrok. Це нормально, хай натиснуть Visit Site.
Адреса, за якою модери відкриватимуть панель (свій домен, Cloudflare Tunnel, VPS…). Для тесту тільки на цьому ПК можна лишити порожнім.
4

Twitch-додаток (вхід модерів)

Через нього модери входять своїм Twitch, а програма перевіряє, чи вони справді модери.

Як створити Twitch-додаток і отримати ключі
  1. Відкрий dev.twitch.tv/console/apps і увійди. Twitch вимагає увімкнену двофакторну автентифікацію на акаунті.
  2. Натисни Register Your Application.
  3. Name: будь-яка унікальна назва, напр. ModDrop-мійканал.
  4. OAuth Redirect URLs: встав посилання з жовтої рамки вище (кнопка «Копіювати»).
  5. Category: Other. Client Type: Confidential. Потім натисни Create.
  6. У списку біля свого додатку натисни Manage. Скопіюй Client ID.
  7. Натисни New Secret і скопіюй Client Secret. Його показують лише один раз.
  8. Якщо зміниш домен ngrok, онови Redirect URL у Twitch-додатку.
5

Додатково

Як отримати ключ GIPHY (безкоштовно)
  1. Відкрий developers.giphy.com/dashboard і увійди або зареєструйся.
  2. Натисни Create an API Key, вибери API (не SDK) і введи будь-яку назву.
  3. Скопіюй API Key сюди. Без ключа пошук GIF теж працює, але через Bing, і результати там гірші.
